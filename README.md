# e-com-polyglot-platform
Platform architecture for the demo e-commerce application avaialble in the e-com-polyglot repo

**Pre-requisites**

* Git

* The docker images used were built from e-com-polyglot repo. Since this project is targeted to run locally the images need to be built and made avaialble to your local **minikube** and/or **kind** cluster.

* Run **bash scripts/build-n-deploy-images.sh** with the required parameters to complete the above mentioned pre-requisite.
